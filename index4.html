📊 Output Layer - Sigmoid Activation

⚡ Sigmoid Activation Function

The output layer uses sigmoid activation to produce a probability between 0 and 1 for binary classification:

σ(x) = 1 / (1 + e^(-x))

Output range: [0, 1] representing probability of malicious traffic
